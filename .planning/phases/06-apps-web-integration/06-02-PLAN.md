| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06 | Information Disclosure | PublicBlogPostsController | high | mitigate | `published: true` filter enforced server-side in `BlogPostsService.findAllPublished()`'s `where` clause and `findPublishedBySlug()`'s post-fetch `if (!blogPost.published)` check — never relies on apps/web to filter client-side |
| T-06-07 | Information Disclosure | PublicBlogPostsController response fields | low | mitigate | Explicit Prisma `select` on both public service methods excludes `updatedById`/`updatedBy`/`createdAt`/`updatedAt` — least-privilege field selection instead of the full model |
| T-06-08 | Elevation of Privilege | PublicBlogPostsController route surface | high | mitigate | The controller declares only `@Get()` handlers (list + by-slug) — no write methods exist on this class at all; the existing protected `BlogPostsController` (create/update/delete) is untouched and stays behind the global `AccessTokenGuard` |
