## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Client search input -> in-memory array filter | User-typed text in `blog-filters.tsx`'s search field is used only as a `.includes()` substring predicate over an in-memory `posts` array (no server round-trip, no persistence, no query construction). |
