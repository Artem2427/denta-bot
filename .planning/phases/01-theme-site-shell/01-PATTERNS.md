Note: `sonner.tsx` uses `useTheme()` WITHOUT a `'use client'` directive — this is a pre-existing bug (RESEARCH.md Pitfall 2). The new `theme-toggle.tsx` MUST include `'use client'` at the top; do not copy the missing-directive mistake from this analog.

**Core pattern to port** (source: CONTEXT.md's fully-transcribed `src/app/components/theme-toggle.tsx`, lines 325-349) — ports as-is, no router dependency, mounted-guard pattern for hydration safety:
```tsx
'use client';

import { Moon, Sun } from 'lucide-react';
import { useTheme } from 'next-themes';
import * as React from 'react';

import { Button } from '@repo/ui';

export function ThemeToggle() {
  const { theme, setTheme } = useTheme();
  const [mounted, setMounted] = React.useState(false);
  React.useEffect(() => {
    setMounted(true);
  }, []);

  if (!mounted) {
    return (
      <Button variant="ghost" size="icon" className="h-10 w-10">
        <Sun className="h-5 w-5" />
      </Button>
    );
  }

  return (
    <Button
      variant="ghost"
      size="icon"
      onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}
      className="h-10 w-10"
    >
      {theme === 'dark' ? <Sun className="h-5 w-5" /> : <Moon className="h-5 w-5" />}
      <span className="sr-only">Перемкнути тему</span>
    </Button>
  );
}
```

## Shared Patterns

### Semantic token normalization (D-03)
**Source:** `packages/ui/styles/theme.css` `@theme inline` block (existing `--color-*` mappings)
**Apply to:** `header.tsx`, `footer.tsx`, `not-found.tsx`, and (per D-03's general rule) all future page-content files in Phase 2/3
```
bg-white / dark:bg-gray-900   → bg-background
bg-gray-50 / dark:bg-gray-900 → bg-muted (or bg-card)
text-gray-900 / dark:text-white → text-foreground
text-gray-600/700 / dark:text-gray-300/400 → text-muted-foreground
border dark:border-gray-800   → border-border
bg-[#1d6be4] / text-[#1d6be4] / hover:text-[#1d6be4] → bg-brand / text-brand / hover:text-brand
```
