<objective>
Build the reusable premium UI primitives every future apps/web component (this phase's shell rebuild, and Phase 2's page content) will compose from: a CVA-variant `PremiumButton`, a `PremiumCard`, a `Container` layout wrapper, and a local `cn()` className helper — all built directly on the `dt-` tokens from Plan 01, with zero dependency on `@repo/ui`. Per D-03, all 4 files land under `apps/web/shared/{components,lib}/`, never under `packages/ui/src/components/`. `PremiumCard`'s padding and `Container`'s generous horizontal gutters embody D-11's "generous whitespace, restraint over shouting" principle at the primitive level, so every consumer inherits it by default rather than re-deriving spacing per page.

Purpose: DESIGN-01 (the palette/radius/shadow system made tangible as consumable components) and DESIGN-03 (baking WCAG AA contrast — D-35's 4.5:1 text-contrast floor, verified below for the coral/navy button pairing — and `focus-visible` states into the primitives once, so every consumer inherits them correctly).
Output: 4 new files under `apps/web/shared/`, ready for Plan 03 (motion) and Plan 04 (shell rebuild) to import.
</objective>
