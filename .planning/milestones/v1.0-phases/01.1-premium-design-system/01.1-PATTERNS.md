### `apps/web/shared/components/theme-toggle.tsx` (component, event-driven)

**Analog:** `apps/web/components/theme-toggle.tsx` (current file, 39 lines — read in full)

**Mount-gated hydration-safe pattern** (lines 8-22) — this is the canonical existing example in this codebase of the exact SSR-safety shape RESEARCH.md Pattern 2 (`useInView`) must replicate:
```tsx
'use client';

import { Button } from '@repo/ui';
import { Moon, Sun } from 'lucide-react';
import { useTheme } from 'next-themes';
import * as React from 'react';

export function ThemeToggle() {
  const { theme, setTheme } = useTheme();
  const [mounted, setMounted] = React.useState(false);

  React.useEffect(() => {
    setMounted(true);
  }, []);

  if (!mounted) {
    return (
      <Button variant="ghost" size="icon" className="h-10 w-10">
        <Sun className="h-5 w-5" />
      </Button>
    );
  }

  return (
    <Button
      variant="ghost"
      size="icon"
      onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}
      className="h-10 w-10"
    >
      {theme === 'dark' ? <Sun className="h-5 w-5" /> : <Moon className="h-5 w-5" />}
      <span className="sr-only">Перемкнути тему</span>
    </Button>
  );
}
```
Reuse exactly for `use-in-view.ts`'s `useState(false)` + `useEffect`-only-flips-true shape (RESEARCH.md Pattern 2). For the rebuilt toggle itself: swap `lucide-react` `Moon`/`Sun` → `@phosphor-icons/react` equivalents, swap `Button` from `@repo/ui` → new premium icon-button primitive. Keep `next-themes`'s `useTheme` hook and the ghost-icon-button shape unchanged (D-04 retrofits styling, not theming logic — `next-themes` `ThemeProvider` in `layout.tsx` stays).

## Shared Patterns

### `'use client'` + SSR-safe mount-gated state
**Source:** `apps/web/components/theme-toggle.tsx` lines 1-16 (full pattern above)
**Apply to:** `use-in-view.ts`, `reveal-on-scroll.tsx`, any new component reading `window`/`IntersectionObserver`/`matchMedia`/`prefers-reduced-motion` state. Never branch initial render output on browser-only values — always `useState(false)` + flip inside `useEffect` (matches RESEARCH.md Pitfall 3/Anti-Pattern warning).

### Scroll/resize event-listener cleanup
**Source:** `apps/web/components/header.tsx` lines 26-30
```tsx
React.useEffect(() => {
  const handleScroll = () => setIsScrolled(window.scrollY > 20);
  window.addEventListener('scroll', handleScroll);
```

**Apply to:** Any new listener-based hook (parallax scroll offset for D-29, magnetic-cursor `mousemove` for D-31) — always return the cleanup function.

**Source:** `apps/web/components/footer.tsx` lines 19-22
**Apply to:** Rebuilt footer's social links and any new external links introduced (e.g. Telegram bot deep-link if added to header/hero).
